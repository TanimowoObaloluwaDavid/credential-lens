What this checks

    
    
      
  • Required structure — context, types, id, awarder, subject, achievement, criteria, dates
    • 
      
  • Proof presence — proof type, cryptosuite, verification method and proofValue
    • 
      
  • Placeholder signatures — a fake signature is worse than none, so it is an error
    • 
      
  • Lifecycle — issue and expiry dates, expiry ordering, credentials already lapsed
    • 
      
  • Revocation — whether a status list exists so the credential can be withdrawn
    • 
      
  • Substance — criteria narrative quality and framework alignment
    • 
    

    

      This judges structure, not truth. A perfectly formed credential can still be worthless.
      Use it to catch malformed documents before you publish them, not as a trust signal.
